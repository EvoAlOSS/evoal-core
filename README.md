Welcome to the source code repository of EvoAl.

## What is EvoAl
EvoAl is a data-science tool-suite for (evolutionary) optimisation, designed to support the setup,
execution, and analysis of optimisation workflows. It provides tools for applying evolutionary
algorithms to complex scientific and engineering problems, including black-box and multi-objective
optimisation tasks.
